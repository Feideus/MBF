# Project Scoping Document — Audio-Synced Reading Platform

Version 1 — Working basis, to be refined

## 1. Problem / Opportunity

Reading is often a sensorially isolated experience: unlike film or video
games, books offer no ambiance adapted to the action unfolding on the
page. Yet many readers — particularly in genres with strong narrative
drive such as thriller, fantasy, crime fiction, or historical fiction —
seek deeper immersion.

Today, there is no simple solution that automatically generates and
synchronizes a soundtrack with one's own reading, scene by scene, based
on the tone of the text.

## 2. Proposed Solution

A community-driven platform that:

- Analyzes a text (uploaded by the user) scene by scene using AI
- Detects the tone of each scene (tension, exposition, dialogue, action,
  melancholy...) and shifts in rhythm
- Automatically matches each scene with a suitable royalty-free audio
  track
- Allows reuse of tracks already generated by other readers for the same
  book (community effect)
- Generates a file in a proprietary format combining text + audio
  tracks, downloadable for reading on an e-reader or phone

## 3. Target Users

Priority audience: readers of genres with strong narrative and emotional
structure:

- Thriller
- Fantasy
- Crime fiction
- Historical fiction

Typical profile: recreational reader, comfortable with digital tools,
seeking immersion, likely already a consumer of multimedia content
(podcasts, series).

## 4. MVP Features

| Feature | Description |
|---|---|
| Text upload | The user imports a public-domain or non-proprietary text |
| AI tone analysis | Automatic segmentation into scenes based on tonal shifts (dialogue / exposition / action...) |
| Audio matching | Each scene matched with a suitable royalty-free track |
| Community library | If the book has already been analyzed, existing tracks are proposed first |
| Proprietary file export | Generation of a file combining text + tracks, readable via the dedicated app |
| Dedicated reader (e-reader/phone) | Minimal application capable of reading the proprietary format and triggering audio in sync with reading progress |
| Free quota | Limited number of AI analyses per month to control costs |

## 5. Future Features (out of MVP scope)

- Handling of copyrighted texts (publisher partnerships, DRM)
- Direct upload from e-readers/proprietary formats (Kindle, etc.)
- Community rating and curation of tracks (votes, favorites)
- Creation/upload of original tracks by the community
- Fine-grained matching customization (preferred music styles, intensity)
- Paid tier with extended quotas or premium catalog
- Multi-device sync (resume reading across devices)

## 6. Technical and Legal Constraints

**Legal**

- MVP restricted to public-domain or non-proprietary texts (no DRM
  handling at this stage)
- Ongoing diligence on the licensing status of audio tracks used
  (verified royalty-free licenses)

**Technical**

- Development of a proprietary file format (text + tracks, or text +
  metadata/timestamps depending on the chosen architecture)
- Development of a dedicated app/reader for e-readers and phones
- Compute cost tied to AI text analysis (to be controlled via quotas and
  community reuse)
- Reliability of automatic scene segmentation (quality of tone detection)
